## 3. 품질 규칙 (검수 게이트)
- Canva AI 생성물은 문구가 바뀜(파일럿 5건: "Tips", "Ai", ①② 누락 등) → **생성 후 원문 대조 검수 단계 필수**
- PPTX 가져오기 직후 Canva 저장 썸네일은 폰트 로드 전 상태라 한글이 가늘게 보일 수 있음 → 검수는 재렌더 결과로
- 가져오기 시 "원+라벨" 콜아웃의 텍스트 컨테이너가 알약 전체로 잡혀 숫자 위치가 틀어짐 → 변환기 개선 필요
- 문구와 이미지가 같은 것을 말해야 함(파일럿 v2: 문구는 시스템지도, 이미지는 이익식 → 불통과)
- 장마다 구체 예시(전→후), 실제 화면엔 주석, 저장 이유(워크시트)·클릭 이유(구체 오퍼)를 기획표 단계에서 정의

## 4. 고객사별 분리
- 브랜드킷·톤앤매너·마스터 레이아웃은 고객사(워크스페이스) 단위로 소유·보관 — 다른 고객사 자산·문구 혼입 금지
- 정보 구조(표지/개념/전후/증거+주석/워크시트/CTA)는 코파운더 공통 방법론으로 재사용, 스킨(색·폰트·로고·사진 톤·말투)은 고객사별
- 식품 등 실물 브랜드는 제품 사진·실사 영상 비중이 커서 마스터 레이아웃 종류 자체가 달라짐(제품컷 표지·조리/섭취 장면·후기 카드)
