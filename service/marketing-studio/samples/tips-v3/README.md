# TIPS 콘텐츠 v3 — 코파운더 SNS 마스터 템플릿

v2(Canva AI 생성) 피드백 반영: 고객이 이해·저장·클릭할 이유가 없었음 → 장마다 구체 예시(전→후), 실제 화면엔 주석, 저장용 워크시트, 구체 CTA(무료 AX 진단).
톤앤매너 일관성을 위해 **이 레이아웃을 마스터로 고정**하고, 이후 정보형 게시물은 이 마스터를 복제해 문구·이미지만 바꾼다.

## 톤앤매너 규칙
| 항목 | 규칙 |
|---|---|
| 색 | 네이비 #16243D · 터쿼이즈 #2DD4BF(진한 #0F9E8C) · 크림 #FAF8F3. 주황은 AX 시스템지도 범례(주인 없는 결정)에만 |
| 배경 | 표지·CTA = 네이비, 본문 = 크림 |
| 고정 요소 | 좌상단 시리즈 라벨, 우상단 페이지 번호, 좌하단 로고 심볼 칩, 우하단 출처·예시 주석 |
| 제목 | 76px ExtraBold, 좌측 88px 여백, 2줄 이내 |
| 용어 | "AX 시스템지도"(결정지도 X) |
| 금지 | TIPS 선정 보장·확률, 최상급, 지어낸 숫자. CTA 장에 "TIPS 선정은 운영사·전담기관 심사로 결정됩니다" |

## 파일
- `tips.html` / `render.py` → `out/TIPS_v3_*.png` (캐러셀 7장 + 광고 1장, 1080×1350)
- `reel.html` / `reel_render.py` → 프레임 렌더 후 ffmpeg로 `out/TIPS_릴스_21초_v3.mp4` (1080×1920, 24fps, 무음)
- `canva/extract.py` → `canva/build_pptx.py` → PPTX → Canva 가져오기(편집 가능한 마스터)
